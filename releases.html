Release notes

What changed in each version of Tagger. The newest is at the top.

Version 1.0.0 24 November 2026Latest

  • First release. An NFC tag reader, writer and automation app in one, with every tool free.
  • Scan: chip, ID, technologies, memory and protection, a genuine-chip check, and link safety checks before anything opens.
  • Write: 16 record types, drag to reorder, a fit check before writing and a read-back check after.
  • Tools: copy, copy to many, erase, format, lock, passwords, encrypted tags, security audit, memory map, raw commands, dumps and compare, batch tagging, QR twin, tag emulation (beta) and a chip guide.
  • Automate: 44 actions and conditions, if and otherwise blocks, variables, seven templates, signed task tags and linked tags.
  • Run tasks from a widget, a home-screen shortcut or a Quick Settings tile, with run, check-in and network logs.
  • Optional power mode with Shizuku for silent Wi-Fi, Bluetooth, mobile data, flight mode and location switches.
  • Encrypted history, saved tags and tasks; password-protected backups; optional app lock.
  • Graphite, Midnight, Daylight and Match phone looks.

Checking your download

The file for version 1.0.0 is called Tagger.apk. It is 3.9 MB (3,922,172 bytes). Its SHA-256 checksum is:

aee4c4b5344f02c0f64285c57efd2e75858573d6f467aad48ea01c7f4fda1d0b

On Windows, run certutil -hashfile Tagger.apk SHA256 and compare. Every version is signed with the same key, so each one installs over the last and keeps what you have saved.

Older versions are on the GitHub releases page.

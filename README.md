# Tagger

Tagger reads, writes, protects and automates NFC tags in one app: chip details, a genuine-chip check, link safety checks, passwords, encrypted tags, a security audit, dumps, batch tagging and tags that run tasks on your phone. Encrypted, no adverts, no account.

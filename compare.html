Tagger does it all in one free app

NFC Tools and NFC Tools Pro are popular, long-standing NFC apps. Tagger reads and writes tags as they do, and adds checks, protection and automation of its own, all free in one app. This page shows only the rows where Tagger does more.

What Tagger does not do

Tagger does not crack MIFARE Classic keys, cannot copy a chip's own ID, and its password, dump and memory tools work on NTAG and Ultralight tags. It is not on Google Play, so it does not update itself.

Where NFC Tools does more

NFC Tools lists more than 200 tasks, has been tested with a long list of chip families including ICODE, DESFire and ST25, and installs and updates from Google Play.

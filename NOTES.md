**Tagger 1.0.0 – first release.** An NFC tag reader, writer and automation app in one, with every tool free.

- **Scan:** chip, ID, technologies, memory and protection, a genuine NXP chip check, and link safety checks before anything opens.
- **Write:** 16 record types, drag to reorder, a fit check before writing and a read-back check after.
- **Tools:** copy, copy to many, erase, format, lock, passwords, encrypted tags, security audit, memory map, raw commands, dumps and compare, batch tagging, QR twin, tag emulation (beta) and a chip guide.
- **Automate:** 44 actions and conditions, if and otherwise blocks, variables, seven templates, signed task tags and linked tags. Run tasks from a widget, a home-screen shortcut or a Quick Settings tile.
- Optional power mode with Shizuku for silent Wi-Fi, Bluetooth, mobile data, flight mode and location switches.
- Encrypted history, saved tags and tasks; password-protected backups; optional app lock.

Android 10 or later, with NFC. Use Tagger only on tags and cards you own or have permission to use – see https://customgpter.github.io/tagger/terms.html#law
